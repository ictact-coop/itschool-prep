# 사이트 내용 고치기 (비개발자용)

준비 소식과 설립 진행상황은 **GitHub 웹사이트에서 파일을 고치면** 1~3분 뒤 사이트에 반영됩니다.
프로그램을 설치할 필요는 없습니다.

- 사이트: https://itschool-prep.data-fc8.workers.dev (도메인 연결 후 https://itschool.ictact.kr)
- 저장소: https://github.com/ictact-coop/itschool-prep

## 시작 전에

1. GitHub 계정이 있어야 하고, 저장소에 **쓰기 권한**이 있어야 합니다. 없으면 관리자에게 초대를 요청하세요.
2. 공개해도 되는 내용인지 먼저 확인합니다.
   - 개인정보, 비공개 회의 내용, **확정되지 않은 지원·협력 사실**은 올리지 않습니다.
   - 빈고 등 재정 협력은 "협의 전"이나 "논의 중"으로만 씁니다.

## 1. 준비 소식 올리기

소식 하나 = 파일 하나입니다. 파일은 `src/content/news` 폴더에 있습니다.

1. https://github.com/ictact-coop/itschool-prep/tree/main/src/content/news 를 엽니다.
2. 오른쪽 위 **Add file → Create new file** 을 누릅니다.
3. 파일 이름 칸에 `날짜-영문단어.md` 형식으로 적습니다.
   - 좋은 예: `2026-12-01-committee-open.md`
   - 안 되는 예: `추진위원모집.md`(한글), `2026 12 01.md`(띄어쓰기), `Notice.md`(대문자)
   - 이 이름이 글 주소가 됩니다 → `/news/2026-12-01-committee-open`
4. 내용 칸에 아래 양식을 붙여 넣고 고칩니다. 양식 파일: [`docs/templates/news.md`](templates/news.md)

```markdown
---
title: 추진위원 모집을 시작합니다
date: 2026-12-01
label: 모집
---

IT학교 설립에 함께할 **추진위원**을 모집합니다.

- 모집 기간: 12월 1일 ~ 12월 13일
- 신청: 첫 화면의 "참여 의향 남기기"
```

5. 아래 **Commit changes…** 를 누르고, 메시지에 무엇을 했는지 적은 뒤(예: `소식: 추진위원 모집 공지`) **Commit changes** 를 누릅니다.
6. 2~3분 뒤 사이트 첫 화면 "준비 소식"을 확인합니다. → [4. 반영 확인](#4-반영-확인)

### 양식 항목 설명

| 항목 | 뜻 | 규칙 |
|---|---|---|
| `title` | 제목 | 60자 이내 |
| `date` | 날짜. 최신 날짜가 위에 나온다 | `2026-12-01` 형식 |
| `label` | 제목 오른쪽 작은 글씨 | 12자 이내. 예: `공지`, `모집`, `확인된 단계`, `예정 게시물` |
| `draft` | (선택) `true`면 사이트에 안 보임 | 쓰지 않으면 공개 |

- `---` 두 줄 사이가 양식이고, 그 **아래가 본문**입니다.
- 본문이 있으면 제목이 링크가 되고 글 페이지가 생깁니다. 본문이 없으면 목록에 제목만 보입니다.
- 첫 화면에는 최신 3건만 나오고, 그보다 많으면 "준비 소식 전체 보기" 링크가 생깁니다.

### 본문 꾸미기

| 쓰는 법 | 결과 |
|---|---|
| `**굵게**` | **굵게** |
| 줄 앞에 `- ` | 글머리 목록 |
| 줄 앞에 `1. ` | 번호 목록 |
| 줄 앞에 `## ` | 소제목 |
| `[보이는 글자](https://주소)` | 링크 |
| 빈 줄 | 문단 나누기 |

사진은 개발 담당에게 요청해 주세요(용량 조절과 대체 텍스트가 필요합니다).

### 고치기·내리기

- **고치기**: 해당 파일 → 오른쪽 위 연필 아이콘(Edit) → 수정 → Commit changes
- **잠시 숨기기**: 양식에 `draft: true` 한 줄 추가
- **완전히 지우기**: 파일 → 오른쪽 위 `…` → **Delete file** → Commit changes

## 2. 설립 단계 바꾸기

첫 화면 "IT학교 설립, 어디까지 왔을까요?"는 [`src/content/steps.yaml`](../src/content/steps.yaml) 하나로 관리합니다.

1. 위 파일을 열고 연필 아이콘(Edit)을 누릅니다.
2. 바꿀 단계의 `status:` 값을 고칩니다.

| 값 | 화면 표시 |
|---|---|
| `done` | 완료 (확인된 사실만) |
| `doing` | 준비 중 |
| `planned` | 예정 |

예: 추진위원 모집이 끝났으면

```yaml
- id: committee
  order: 3
  title: 추진위원 모집
  summary: 발기인과 공동 설립 주체 구성
  status: done
```

3. Commit changes 로 저장합니다.

주의
- 줄 앞의 **띄어쓰기(두 칸)** 를 지우거나 늘리지 마세요. 들여쓰기가 틀리면 반영되지 않습니다.
- `title`은 30자, `summary`는 40자 이내.
- 단계를 새로 넣거나 순서를 바꾸려면 `order` 숫자를 고칩니다. 확신이 없으면 개발 담당에게 요청하세요.

## 3. 그 밖의 문구

첫 화면 문구(소개, 학제 지도의 과목·예시 도구, '한눈에 보기' 질문과 답, 참여 안내 등)는 `src/data/home.ts`에 있습니다.
카톡·SNS 미리보기 이미지는 `public/og.png`(1200×630)입니다. 문구를 바꾸려면 개발 담당에게 요청하세요.
프로그램 코드 파일이라 따옴표 하나만 지워도 사이트가 반영되지 않으므로, **개발 담당에게 요청**하는 것을 권장합니다.
직접 고친다면 작은따옴표(`'…'`) **안의 글자만** 바꾸세요.

## 4. 반영 확인

1. 저장 후 저장소 첫 화면 https://github.com/ictact-coop/itschool-prep 에서 방금 커밋 옆 표시를 봅니다.
   - 🟡 노란 점: 반영 중 (1~3분)
   - ✅ 초록 체크: 반영 완료 → 사이트를 새로고침해 확인
   - ❌ 빨간 X: **반영되지 않음**. 사이트는 이전 상태 그대로입니다(망가지지 않습니다).
2. 빨간 X가 뜨면
   1. X 표시 → **Details** 를 누릅니다(Cloudflare 빌드 기록이 열립니다).
   2. 기록에서 한국어 안내를 찾습니다. 예:
      - `date: date는 2026-12-01 형식으로 적어 주세요.`
      - `label: label(오른쪽 작은 글씨)을 적어 주세요.`
      - `준비 소식 파일 이름 "…"를 쓸 수 없습니다. 영문 소문자·숫자·하이픈(-)만 써 주세요.`
      - `status: status는 done(완료), doing(준비 중), planned(예정) 중 하나로 적어 주세요.`
   3. 안내대로 파일을 다시 고쳐 저장하면 됩니다.
   4. 원인을 모르겠으면 커밋 주소를 개발 담당에게 보내 주세요.

## 자주 묻는 것

- **잘못 올렸는데 바로 내리고 싶어요** → 파일에 `draft: true`를 추가하거나 파일을 삭제하세요. 2~3분 뒤 사라집니다.
- **여러 명이 동시에 고쳐도 되나요?** → 같은 파일을 동시에 고치면 나중 사람이 저장할 때 GitHub가 알려 줍니다. 새로고침 후 다시 고치세요.
- **신청자 명단은 어디서 보나요?** → 이 저장소가 아니라 관리 화면(`/admin`)에서 봅니다. 신청 정보는 저장소에 절대 올리지 않습니다.
